Entering Veyra

Night. Elias enters Veyra carrying the Echo Lantern. His face is never shown. Footsteps, wind, the lantern glass rattling.

This is a look-test, drawn in code to lock the style before anyone paints. Treat it as the underlay to trace and improve, not the final art.

Rules for every scene

Two colours glow

Amber is the living present and appears only on Elias's scarf here. Teal is the Echo Lantern. Elias is the only thing that carries both, which quietly sets up the twist.

No face

Back or three-quarter view, a wide hat brim and a high collar. The face appears only in the final memory.

No gradients

Shading is hard colour steps. Use dithering (the checker pattern) only for sky, fog and light falloff.

Light is code

Paint everything unlit. The game brightens pixels near the lantern by one palette step. Hidden symbols go on a separate residue layer that shows only inside the light.

Palette · 23 colours

Built from the team's existing eight tokens (ink, soot, mud, olive, dried blood, bone, amber, teal) with extra steps for shading. Paste the .hex list into Pixelorama, LibreSprite or Lospec so nobody picks colours by eye.

Fog, wind, leaves and the lantern glow are done in code. In Phaser, set pixelArt: true and roundPixels: true and scale by exactly 4. Export PNG and skip lossy WebP and trimming for these files, or the layers stop lining up and the pixels smear.

How to make it

  1. Post this page in Team HQ first. The locked direction is comic ink-noir and Bhumi and Arya are drawing in it, so switching to pixel art needs a yes from the team.
  2. Make a 480 × 270 canvas, load the palette above, and make one layer per file in the table.
  3. Block in silhouettes with flat colour: sky, far roofs, tower, houses, street. Get the shapes right before any detail.
  4. Add detail one layer at a time: timber beams, windows, cobbles, grime pixels. Dither only the sky and fog.
  5. Draw Elias on a 32 × 58 frame: one idle pose, then 4 walk frames (stride, pass, stride, pass). Check the outline matches the figure in later scenes.
  6. Export each layer as PNG at 1×, named as in the table, and hand it to whoever owns the Opening scene.

Free tools

PixeloramaUse this

Free and open source. Windows app or runs in the browser. Layers, palettes, animation timeline and dithering.

LibreSprite

Free fork of an old Aseprite. Very good for sprite sheets and onion-skin animation.

Piskel

In the browser, nothing to install. Quick for small sprites like the lantern and Elias's walk.

Lospec

Palette files, a pixel editor and short tutorials on dithering and walk cycles.

Krita

Free painting app the team already uses. Has pixel brushes; turn off anti-aliasing.

Aseprite

The standard tool, but it costs money unless you build it from source. Skip it tonight.
