Veyra Interface

Title, pause and settings, the casebook, the evidence popup and the ending, all in the same 27-colour pixel set as the scenes.

Every panel and button is a 9-slice: the corners stay crisp and only the middle stretches, always by whole pixels. Labels use a 3 × 5 bitmap font shipped as a sheet, so UI text has the same pixels as the art.

Title screen

Every 9 s the lantern dips and the tower's minute hand twitches toward 2:18, then snaps back. The logo is printed misregistered: an amber copy one pixel left, a teal copy one pixel right, the bone letters on top.

Casebook

Cork board with a wooden frame. Cards are 9-slices; pins and the CONTRADICTION / IDENTITY UNKNOWN stamps are separate sprites; the yarn is a 1-pixel dried-blood line drawn in code with a 1-pixel ink shadow under it.
